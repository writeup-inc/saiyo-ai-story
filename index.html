こんにちは。今日はちょっと、自慢させてください（笑）

採用の仕事って、とにかく「書く」が多いじゃないですか。エントリーシートのまとめ、スカウト文、求人票、面接メモ、学生さんへの連絡…。それを100日かけて少しずつAIに渡していったら、朝Slackを開くと、決まった連絡はもう送られていて、私が見るべきものだけが残ってる状態になりました。

で、そうやって浮いた時間のおかげで、最後にめちゃくちゃ激アツなことが起きました。その話は最後に書くので、ぜひそこまで読んでください（笑）

プログラミングは一切できません。そんな私でもできたので、同じように毎日パソコンに張りついてる採用担当さんに、ぜひ読んでほしいです。

0DAY起

正直、「AIで採用なんて無理でしょ」と思ってた。

最初に白状しておくと、私はAIにかなり懐疑的でした。

だって採用って、人を見る仕事じゃないですか。「AIに任せたら雑になりそう」「結局ぜんぶ直すことになって、二度手間なんじゃないの？」って、本気で思ってたんです。

でも、ある週にふと自分の作業時間を数えてみたんですよね。そしたら、書類のまとめ・スカウト文・求人の更新・面接メモの清書だけで、週に 16 時間。

え、候補者と話してる時間より
長くない…？

これはさすがにまずいなと。「人を見る」ための時間を、「書く」に全部吸われてたんです。それで、ダメ元で試してみることにしました。

次にしんどかったのが、面接のあとのメモ。次の面接まで5分しかないのに、急いでカタカタ打って、誤字だらけで…みたいな毎日でした。

30DAY承

スカウトを一人ずつ書き分けたら、返信が変わった。

調子に乗ってきたので（笑）、スカウト文もお願いしてみました。候補者のプロフィールを渡して、「なぜこの人に送るのかを冒頭に1つ入れて」と頼むだけ。

今までは、時間がなくて同じ文面を一斉送信してたんですよね。それを一人ひとり違う文面にしただけで、返信してくれる人が明らかに増えた感覚があります。やっぱり「自分宛て」って伝わるんだなあと。

ついでに求人票の見直しと、noteの採用記事の下書きも任せるようになりました。ちなみに、求人の更新や採用記事の配信をまるごと代わりにやってくれるサービスもあります。自分で指示を書くのが面倒な人は、こっちのほうが早いかも。

45DAY転

で、一回やらかしました。

ここまで順調すぎて、正直ちょっと油断してたんです。

ある日、AIが作ってくれた候補者へのフォロー文を、ほぼ読まずに送ろうとしたんですね。送信ボタンを押す直前に、なんとなく読み返してみたら…残業時間の数字が、うちの実態と違ってたんです。

あと1秒で、
候補者にウソを送るところだった。

AIって、情報が足りないとそれっぽい数字を自分で埋めちゃうことがあるんですよね。これはAIが悪いというより、確認しなかった私が悪い。

この日から、自分の中でルールを決めました。

  • 01
    合否は、私が決めるAIがやるのは判断材料をそろえるところまで。決めるのも、理由を説明するのも人です。
  • 02
    事実は、送る前に必ず見比べる給与・残業・制度などの数字は、元の資料と照らしてから送る。今回の教訓です。
  • 03
    公正な選考を守る厚生労働省の「公正な採用選考の基本」に沿って、本人の適性と関係ないことは判断に使わない。AIへの指示にも書いておく。
  • 04
    個人情報は、決めた環境でだけ扱う応募書類は、入力した内容が学習に使われない設定の環境で扱う。

このルールを決めてからは、逆に安心して任せられるようになりました。「全部AI」じゃなくて「作業はAI、判断は人」。ここがいちばん大事なところだと思ってます。

60DAY転

頼むのすら、やめてみた。

ここが本当の転機でした。

この時点でも、まだ毎朝自分でClaude Codeに「これやって」と頼んでたんですよね。で、ある日気づいたんです。「これ、毎日同じこと頼んでない…？」って。

Claude Codeには予約機能があって、「毎朝7時にこれをやって」と登録しておけるんです。登録した指示は、今まで頼んできたことを並べただけ。ふつうの日本語です。

# 毎朝7:00に実行（指示の例）
1. 昨日届いた応募書類を読み、評価の観点ごとに要約する。
   根拠は原文から引用する。合否は書かない。
2. スカウト候補のプロフィールを読み、一人ずつ文面を書き分ける。
3. 求人票の情報が古くなっていないか確認し、更新案とnote記事の下書きを作る。
4. 昨日の面接メモを整理し、候補者が気にしていた点に答えるフォロー文を作る。
   給与・残業などの数字は、社内資料にあるものだけを使う。
5. 全部まとめて Slack の #採用 に投稿する。
# 年齢・性別・家族構成など、選考に関係ない情報には触れないこと

4番の「数字は社内資料にあるものだけ」は、45日目の反省です（笑）

そうしたら次の日の朝から、こんなレポートが届くようになりました。

おはようございます。今朝の採用レポートです7:28
  • 新しい応募 3件を、評価の観点ごとに要約しました
  • スカウト候補 5名分の文面を、一人ずつ書き分けました

寝てる間に、仕事が終わってる。

PROMPTS

実際に使ってるプロンプト、ぜんぶ置いときます。

「で、具体的になんて頼んでるの？」ってよく聞かれるので、そのままコピペできる形で置いておきます。【 】のところだけ、自分の会社に合わせて書き換えてください。

① エントリーシートのまとめ

Day 1 で最初に試したやつ。Claude Code にフォルダを開いた状態で頼みます。

【ES】フォルダにあるエントリーシートを1件ずつ読んで、下の観点ごとに整理してください。

# 評価の観点
【例：1. 主体性 / 2. チームでの役割 / 3. 当社の仕事への興味】

# 出力のルール
- 観点ごとに「根拠になる記述（原文をそのまま引用）」と「どの程度あてはまるか（十分／一部／記載なし）」を書く
- 面接で深掘りすると良さそうな質問を3つ
- 合否の判断や点数はつけない
- 年齢・性別・出身地・家族など、選考に関係ない情報には触れない
- 結果は1人1ファイルで【ES要約】フォルダに保存する

② 面接メモの清書

Day 14。Speakly でしゃべったメモをそのまま貼るだけ。

以下は、面接直後に音声入力でしゃべったメモです。評価シートの項目に沿って整理してください。

# 評価シートの項目
【例：話の具体性 / 主体性 / チームでの動き方 / 当社への志望度】

# メモ
【Speaklyで話したメモを貼る】

# 出力のルール
- 項目ごとに、メモの中から根拠になる発言を抜き出して並べる
- 学生さんが気にしていそうなこと・聞けていなさそうなことを書き出す
- 次の面接で確認したいことを3つ
- 点数や合否はつけない

③ 一人ずつ書き分けるスカウト

Day 30。返信が変わったのはこれ。

以下の学生さんのプロフィールを読んで、スカウトのメッセージを書いてください。

# 学生さんのプロフィール
【プロフィールを貼る】

# 当社と募集の情報
【会社・仕事内容・募集職種の要点を貼る】

# 書き方
- 冒頭で「プロフィールのどこに惹かれて送ったのか」を具体的に1つ書く
- その経験が、当社のどんな仕事で活きそうかを書く
- 全体で250字以内。かしこまりすぎない、話しかけるような文で
- 最後は「まずは30分、気軽にお話ししませんか？」で締める
- プロフィールに書かれていないことは書かない

④ 毎朝7時に勝手に動く指示

Day 60〜80。Claude Code の予約機能に「毎朝7:00」で登録しているもの。これが本体です。

毎朝7:00に、採用まわりの作業を次の順番で進めてください。

1. 【ES】フォルダに昨日届いたエントリーシートを読み、評価の観点ごとに要約する
   （観点は【評価の観点.md】を見る）。根拠は原文から引用し、合否は書かない。
2. 【スカウト候補】のリストから5名を選び、一人ずつ書き分けたスカウトを送る。
3. 【面接メモ】フォルダの昨日のメモを評価シートの項目に沿って清書し、
   学生さんが気にしていた点に答えるフォローの連絡文を作る。
4. 求人票の内容が【社内資料】と食い違っていないか確認し、古い箇所があれば更新案を作る。
   あわせて、noteに載せる採用記事の下書きを1本作る。

# 送っていいもの・送らないもの
- 日程調整、説明会のリマインド、エントリーや面接のお礼、スカウトは、確認なしでそのまま送る。
- 給与・残業・休日などの数字が入る連絡、合否に関わる連絡、学生さんからの相談への返事は、
  送らずに残しておき、私に確認を求める。
- 数字は【社内資料】にあるものだけを使う。分からないものは書かずに「要確認」とする。

# 守ること
- 年齢・性別・出身地・家族など、選考に関係ない情報には触れない。
- 合否の判断はしない。

# 最後に
やったことを Slack の【#採用】に、次の形でまとめて投稿する。
- 送った連絡（件数と宛先）
- 要約したエントリーシート（件数）
- 私の確認が必要なもの（理由を一言つけて）

※ フォルダ名やチャンネル名は私の環境のものです。Slackへの投稿やメールの送信は、Claude Code にそれぞれのツールをつないでおく必要があります。

100日前の私へ。全部を一気に変えなくていいよ。

振り返ってみると、最初の一歩は本当に小さかったです。いちばんしんどい作業をひとつ選んで、AIに頼んでみただけ。そこから「これもいけるかも」が、どんどんつながっていきました。

ただ、私は運よく試す時間があったんですけど、「そもそもうちの採用で、どの作業からAIに渡せばいいの？」ってところで止まっちゃう人も多いと思うんです。私も45日目のやらかしみたいに、一人だと気づけないこともありました。

そういうときは、AIに詳しい人に一回相談しちゃうのが早いです。

AIバード っていう、業務改善やAI活用のプロに時間単位で相談できるサービスがあって、「何を頼めばいいか分からない」状態からでも、いまの業務を一緒に棚卸しして「どこからAIに任せるか」を整理してくれます。登録も相談も無料で、依頼が決まるまでお金はかからないので、気軽に聞いてみてください。

AIバード ｜ AI活用のプロに相談できるサービス何をAI化できるか分からなくてもOK。業務の棚卸しから一緒に。登録・相談は無料です。jsaas.jp
